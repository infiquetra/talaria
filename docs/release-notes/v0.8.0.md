# Talaria v0.8.0

Talaria is a terminal client for the Hermes agent backend. Version 0.8.0 adds
an optional workspace and menu, local themes, improved pickers, and client-side
voice. Before upgrading from 0.6.5, read the
[migration guide](https://github.com/infiquetra/talaria/blob/v0.8.0/docs/migrating-from-0.6.5.md).

## Read this part first

- **The workspace is optional.** The default inline view keeps finished output
  in native terminal scrollback. The workspace uses the whole screen; while it
  is open, native scrollback and terminal search do not cover the conversation.
  Finished output waits in memory until you return to inline view, so a process
  crash can lose it.
- **Client voice is opt-in.** Capture and playback helpers run on your machine
  and must be installed and configured separately. Sending audio to a remote
  gateway requires explicit `remote_audio = true`; attaching remotely alone
  does not grant that permission.
- **Check your gateway.** The pinned Hermes contract is v0.22.4; Talaria needs
  the session authority introduced in Hermes v0.22.3. Run `talaria doctor` to
  check the gateway you use.

## What is new

- **Voice choices (#424).** The client voice system adds local audio and
  fleet-aware routing alongside the existing Hermes gateway backend. It is
  off unless you configure it; existing text interaction remains available.
- **Local audio helpers (#426).** Set `backend = "client-bridge"` under
  `[voice]` and configure `capture_command` and `playback_command` as
  argument arrays. Capture uses a local helper and Hermes speech services;
  missing helpers produce a notice. Remote audio needs its own opt-in.
- **Interruptible speech and summaries (#427).** Starting a recording stops
  local playback; `/voice stop` stops it too. Set `render_mode = "digest"`
  under `[voice]` for a deterministic spoken summary, or use `/voice mode`
  with `full`, `summary`, or `alerts` for the current target.
- **Voice across the fleet (#428).** Recording follows the selected request
  or session rather than silently moving with focus. Spoken alerts can be
  enabled with a `speech` list under `[notifications]`, for example
  `speech = ["needs_you", "done", "failed"]`; the list is empty by default.
  Permission answers still require Enter.
- **Workspace and panel (#480).** Set `work_panel = true` under `[ui]` to
  start with the workspace, or use Alt+D or `/layout panel` for the current
  view. At 112 columns by 28 rows the panel docks on the right; on smaller
  screens it opens as an overlay.
- **Work overview (#481).** The panel brings together waiting attention,
  the current goal and turn, explicit verdict, tasks, and agents. Unknown
  details stay labelled unknown.
- **Menu bar (#482).** Set `menu_bar = true` under `[ui]`, or use Alt+I
  to toggle it and `/layout menu` to focus it. The keyboard menu opens
  existing actions. It collapses on narrow screens; below 16 rows it opens
  temporarily without reserving a row.
- **Theme files (#485).** Choose a local theme with `file = "terminal"`
  under `[theme]`, or create `~/.talaria/themes/<id>.toml` and use
  `/theme use <id>`. `/theme reload` rereads the active file; session
  commands do not save the selection.
- **Theme coverage (#486).** The theme catalogue now supplies colours across
  the interface, including menus and overlays, while respecting terminal
  colour settings.
- **Built-in themes (#487).** Set `[theme] file` to `"terminal"`,
  `"ember"`, or `"paper"`, or choose one with `/theme use`. Terminal
  follows terminal defaults, Ember is dark and Paper is light.
- **Search-first model picker (#488).** `/model` or Alt+P opens a searchable
  list with details; setup entries lead to provider configuration without
  losing the picker context.
- **Providers dialog (#489).** `/providers` uses the shared picker frame,
  with searchable lists and a details area for provider setup and accounts.
- **Reasoning effort status (#502).** The status bar marks a requested effort
  that the model does not offer and shows both levels when Hermes reports a
  lower applied level.
- **Skills and Hub counts (#503).** The Skills tab labels installed skills and
  shows how many are on in its footer. Hub search asks for up to 50 items and
  distinguishes those shown from source items fetched before deduplication.
  The fetched count is not a total number of matches.

## What changed from 0.6.5

Talaria is now a Rust client that attaches to the Hermes session authority.
Configuration still lives at `~/.talaria/config.toml`, but some older keys
are retired and produce notices. Read the
[migration guide](https://github.com/infiquetra/talaria/blob/v0.8.0/docs/migrating-from-0.6.5.md)
for upgrade and coexistence steps.

## Install

Build the tagged source using the Rust toolchain in `rust-toolchain.toml`:

```bash
git clone --branch v0.8.0 https://github.com/infiquetra/talaria
cd talaria
cargo build --release
target/release/talaria --version
```

See the [installation guide](https://github.com/infiquetra/talaria/blob/v0.8.0/docs/install.md)
for distribution options. Talaria is not published under this name on crates.io,
npm, or the Python Package Index; similarly named packages there are not this
release.

## Works with Hermes

The vendored contract is pinned to Hermes v0.22.4. Gateway capabilities and
configured speech services depend on the connected Hermes installation;
`talaria doctor` reports available capabilities.

## Staying on 0.6.5

You can continue using 0.6.5 or Hermes's native terminal interface while
reviewing the [migration guide](https://github.com/infiquetra/talaria/blob/v0.8.0/docs/migrating-from-0.6.5.md).

## Known limits

- The workspace does not put its live conversation in native terminal
  scrollback until returning to the inline view.
- Local voice requires separately installed helpers and configured Hermes
  speech services. Remote audio is disabled until explicitly allowed.
- Hub fetched counts include duplicates from different sources and are not a
  complete match total.
- macOS release archives are not Apple Developer ID notarized.
