# Talaria v0.9.3

Talaria 0.9.3 is the stable follow-up to 0.9.1. It includes the changes
staged in 0.9.2 plus a session-search fix. The 0.9.2 tag is available as
source, and its binary release was cancelled.

## Read this part first

- Workflow results can report failed agents even when the script completed.
  Check the named agents and any work that remains on disk.
- Use `talaria workflow result <run>` to read a saved result and
  `talaria workflow resume <run>` to continue work.
- Open `/theme` to preview and save a theme for the current profile.
  Use `/theme report` for the detailed report.

## What is new

- Session search retains the typed query and stays ready for input if the
  picker's connection finishes while the search field is open. Ctrl+C can
  still interrupt the current turn while you search.
- Stopped workflow agents can wait for your decision. A run can resume agents
  it interrupted while keeping results from agents that finished. Results
  report failed or cut-short agents, unstarted phases, and remaining work.
- Talaria ships 15 built-in themes, clearer keyboard help, and more readable
  pickers and overlays in narrow terminals.
- Talaria keeps credential paths out of attachments, checks local workflow
  files before reading them, and disables repository Git hooks and filters
  during worktree recovery.

## What changed from 0.6.5

Talaria now attaches to the Hermes session gateway as a Rust terminal client.
Read the [migration guide](https://github.com/infiquetra/talaria/blob/v0.9.3/docs/migrating-from-0.6.5.md)
before carrying an older configuration forward.

## Install

Download a prebuilt archive from the release page. Homebrew can install or
upgrade Talaria once its tap has the updated formula:

```bash
brew install infiquetra/talaria/talaria
talaria --version
```

To build from source with the toolchain in `rust-toolchain.toml`:

```bash
git clone --branch v0.9.3 https://github.com/infiquetra/talaria
cd talaria
cargo build --release --locked
target/release/talaria --version
```

Talaria is not published under this name on crates.io, npm, or the Python Package Index.

## Works with Hermes

The bundled contract is Hermes v0.23.1 (commit `3b421578`). The oldest tested
gateway is v0.23.0. Run `talaria doctor` to see the version of the gateway
you use.

## Staying on 0.6.5

You can keep using 0.6.5 or Hermes's native terminal interface while you review
the migration guide.

## Known limits

- The optional full-screen workspace keeps finished output in memory until
  you return to the inline conversation, where the terminal owns scrollback.
- Voice is opt-in and uses separate capture and playback helpers. Sending
  audio to a remote gateway requires explicit permission.
- macOS release archives are not Apple Developer ID notarized.

## What was checked

The terminal regression test holds the picker's connection until a query is
underway and Ctrl+C has interrupted the turn. It then verifies that the next
key continues the same search. The tagged release workflow tests the workspace,
builds and verifies the four platform archives, and publishes their checksums.

In a live terminal inside tmux, the 0.9.3 candidate opened session search,
accepted a query, returned to the composer, received a Hermes reply, and
exited cleanly.
