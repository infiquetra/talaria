# Talaria v0.8.1

Talaria is a terminal client for the Hermes agent backend. Version 0.8.1 reports seat status to a Herdr terminal. Before upgrading from 0.6.5, read the [migration guide](https://github.com/infiquetra/talaria/blob/v0.8.1/docs/migrating-from-0.6.5.md).

## Read this part first

- **The workspace is optional.** The default inline view keeps finished output
  in native terminal scrollback. The workspace uses the whole screen; while it
  is open, native scrollback and terminal search do not cover the conversation.
  Finished output waits in memory until you return to inline view, so a process
  crash can lose it.
- **Client voice is opt-in.** Capture and playback helpers run on your machine
  and must be installed and configured separately. Sending audio to a remote
  gateway requires explicit `remote_audio = true`; attaching remotely alone
  does not grant that permission.

## What is new

- **Report the seat state to the terminal, behind the existing report_state setting** (#535)
- **[DEFECT] TUI: eliminate duplicate composer border lines when resizing a background Herdr seat tab** (#641)

Set `report_state = false` under `[herdr]` to turn seat reporting off. The [Herdr seat guide](../herdr-seat.md) shows how a lead reads and drives a Talaria seat.

## What changed from 0.6.5

Talaria is now a Rust client that attaches to the Hermes session authority.
Configuration still lives at `~/.talaria/config.toml`, but some older keys
are retired and produce notices. Read the
[migration guide](https://github.com/infiquetra/talaria/blob/v0.8.1/docs/migrating-from-0.6.5.md)
for upgrade and coexistence steps.

## Install

Build the tagged source using the Rust toolchain in `rust-toolchain.toml`:

```bash
git clone --branch v0.8.1 https://github.com/infiquetra/talaria
cd talaria
cargo build --release
target/release/talaria --version
```

See the [installation guide](https://github.com/infiquetra/talaria/blob/v0.8.1/docs/install.md)
for distribution options. Talaria is not published under this name on crates.io,
npm, or the Python Package Index; similarly named packages there are not this
release.

## Works with Hermes

The Hermes pin is unchanged at v0.22.4.

The vendored contract is pinned to Hermes v0.22.4. Gateway capabilities and
configured speech services depend on the connected Hermes installation;
`talaria doctor` reports available capabilities.

The seat acceptance run used these Herdr releases:

- Herdr version: herdr-app 0.1.15
- hc version: hc 0.1.21

## Staying on 0.6.5

You can continue using 0.6.5 or Hermes's native terminal interface while
reviewing the [migration guide](https://github.com/infiquetra/talaria/blob/v0.8.1/docs/migrating-from-0.6.5.md).

## Known limits

- The workspace does not put its live conversation in native terminal
  scrollback until returning to the inline view.
- Local voice requires separately installed helpers and configured Hermes
  speech services. Remote audio is disabled until explicitly allowed.
- Hub fetched counts include duplicates from different sources and are not a
  complete match total.
- macOS release archives are not Apple Developer ID notarized.
