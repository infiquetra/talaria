# Public-Safe Infiquetra Summary

This repository is maintained by Infiquetra.

## Development guidance

- Use the commands and conventions documented in this repository.
- Keep changes focused and covered by relevant tests.
- Do not commit secrets or local environment files.
- Use pull requests for non-trivial changes.
- Treat Hermes Agent's public API and gateway behavior as the integration contract.

## Internal standards

Infiquetra maintainers also use private organization standards for security, delivery, and AI-assisted development. Those standards are not copied here because this repository is public.

Public contributors should follow the repository-local guidance and raise a focused issue when a project decision is unclear.
