`talaria/ui/app.py:1208` · lens `accessibility-human-usability` · dimension `contrast-zoom-motion-responsiveness` · raised by accessibility · confidence 100 · route `safe_auto` -> `review-fixer` · **critical**

**Why it matters.** An operator who sets ui.reduced_motion = true still gets eased animated scrolling on every arrow, PageUp, PageDown, Home and End press, which is the dominant motion surface in this interface, so the accessibility setting silently fails at the one thing it exists to do.

**Suggested fix.** After talaria/ui/app.py:1208 add self.animation_level = "none" if reduced_motion else self.animation_level, then add a regression test sampling transcript.scroll_y after scroll_end() under reduced motion.
