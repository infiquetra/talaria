#### 44. (P1) Theme import writes through a symlink outside config

`talaria/config.py:346` · lens `security` · dimension `input-trust-boundaries-injection` · raised by security, api-contract, architecture · confidence 100 · route `manual` -> `review-fixer`

**Why it matters.** The cycle-1 repair added symlink resolution to atomic_replace_bytes so save_theme could follow a config.toml symlinked into a dotfiles repository. Its other caller, write_user_theme, inherited the widened contract unasked, so a symlink planted at <config>/themes/<slug>.json makes talaria theme import overwrite whatever that link points at, outside the config directory, exiting 0 and preserving the target's mode so nothing signals the write. **Evidence.**

- talaria/config.py:346 — target = path.resolve() if path.is_symlink() else path, added by the cycle-1 repair; the pre-repair body did os.replace(temp_path, path) with no resolution

#### 52. (P2) Read-only runtime guard misses pathlib and io writes

`tests/ui/test_diff_viewer.py:52` · lens `testing` · dimension `behavior-sensitive-assertions` · raised by testing · confidence 100 · route `safe_auto` -> `review-fixer`

**Why it matters.** The autouse fixture's docstring promises to make any runtime write fail loudly, and every diff-viewer test runs under it.
