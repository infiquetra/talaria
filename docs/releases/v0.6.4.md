# Talaria v0.6.4

Talaria v0.6.4 is the residual `/config` remount release after v0.6.3.
Selecting a local profile through the live Target control loads that
profile's editable schema and masked Environment rows. Stay, Discard,
Save, and one-shot Reveal then run on those remounted controls.

Read the limits first. This file is the candidate release note for the
v0.6.4 line; installed acceptance evidence is recorded against the
published tag.

## Read this part first

Carried forward from earlier releases and still true:

- **No person has driven the interface on Linux.** The suite runs there in continuous
  integration; nobody has used it there. macOS remains the supported platform.
- **A credential your shell exported before Talaria started stays visible** in the process
  environment for the life of that process. Use the credential file.
- **Host administration is read-only status.** Update checks and receipts, local-model
  status/catalog/hardware/jobs/search, and gateway-migration plans may be shown. The
  workspace offers no Hermes-update, local-model mutation, or gateway-migration action.
- **Revealed plaintext is presentation-ephemeral.** It may exist only in the
  in-flight response and the active reveal overlay. It is never added to
  domain state, notices, logs, recordings, or reprs, and is wiped on close or
  timeout.

New to this line:

- **Target load remounts the dynamic Hermes subtree.** Updating only
  already-mounted row keys left a newly selected profile without editors
  or a Reveal control. The Talaria-owned branch stays mounted; Hermes
  groups are replaced and awaited before selection reports complete.
- **Target loads do not rewrite session home.** Schema, config, and env
  are fetched with the requested `(connection, profile)` pair and that
  connection's client. A late reply for a previous target cannot repaint
  the selected one.

## What this release adds

- Live `/config` target selection mounts the selected profile's schema
  and masked Environment rows, and removes the previous target's rows.
- Stay keeps the old target and edit with no I/O. Discard clears the
  edit and loads the new target. Save writes and re-reads the old target
  before the new target loads; a failed Save keeps the edit.
- Reveal on the remounted Environment row stays one-shot. The value is
  shown once, then cleared on close or timeout.
