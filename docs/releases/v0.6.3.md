# Talaria v0.6.3

Talaria v0.6.3 is the residual configuration release after v0.6.2. This note
covers the transport half that is already in the tree: gated-origin policy,
live gated REST/WS composition, and product-owned gateway Start/Stop. Live
workspace target switching and secret reveal remain a later unit.

Read the limits first. This file is an unreleased candidate note; installed
acceptance evidence is recorded against the published tag.

## Read this part first

Carried forward from earlier releases and still true:

- **No person has driven the interface on Linux.** The suite runs there in continuous
  integration; nobody has used it there. macOS remains the supported platform.
- **A credential your shell exported before Talaria started stays visible** in the process
  environment for the life of that process. Use the credential file.
- **Host administration is read-only status.** Update checks and receipts, local-model
  status/catalog/hardware/jobs/search, and gateway-migration plans may be shown. The
  workspace offers no Hermes-update, local-model mutation, or gateway-migration action.

New to this line:

- **Loopback token refresh is not widened to remote HTTP.** `require_fetchable_origin`
  still refuses `http://10.220.1.139` and hostname HTTP. Gated sessions use
  `require_gated_origin`, which accepts HTTPS anywhere and plain HTTP only for
  an explicit `auth="gated"` connection whose host is a literal RFC1918 address.
- **Gated credentials are never invented.** Missing or rejected remote login
  stays a re-authenticate / blocked state. WS tickets are minted per dial and
  are not compared to fold inventory rows.
- **Gateway Start/Stop are REST commands**, not wake-word RPC and not
  `POST /api/rpc`. They poll `/api/status` for at most 30 seconds and report
  the observed running state.

## What this release adds

- A gated origin validator separate from loopback credential refresh.
- Live composition that selects `GatedTicketProvider` for `[connections.<id>]
  auth="gated"` and keeps `LoopbackTokenProvider` for local loopback rows.
- `StartGateway` and `StopGateway` command types plus
  `SettingsClient.start_gateway` / `stop_gateway`.
