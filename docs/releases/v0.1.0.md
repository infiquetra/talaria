Talaria is an experimental, Hermes-native terminal UI. This is its first release.

It dials a Hermes gateway it did not launch, runs a session in a terminal interface with sub-agent work broken out into its own rows, and can record everything it saw and replay it later with no gateway at all.

## Read this part first

Talaria's [v0.1 daily-driver verdict](https://github.com/infiquetra/talaria/blob/v0.1.0/docs/analysis/2026-08-02-v0-1-daily-driver-verdict.md) reads **READY**, which is narrower than it sounds. It means every row of that document's evidence table is measured or met, across the requirements it was scoped to cover. It does not mean these are true:

- **No person has driven the interface on Linux.** The test suite runs there in continuous integration, pseudo-terminal and process-surface tests included. Nobody has actually used it there.
- **No run on either platform has used a real terminal emulator.** Every measurement behind the verdict was taken against a bare pseudo-terminal.
- **Gateway method compatibility is proven at the top level only** — a response's own key set and each value's kind, not nested payloads. The same measurement that cleared that row found two pinned shapes wrong.
- **`terminal.read.respond` has no runtime evidence at all.**
- **A credential your shell exported before Talaria started is still visible** in the process environment for the life of the process. Talaria adds none of its own and refuses an endpoint carrying one, but it cannot remove what it inherited. Use the credential file.
- **The test suite fails intermittently** — twelve runs green in thirteen, undiagnosed.

The gaps that document was built to find are closed. The ones it was never scoped to look for are open. Treat the six items above as the actual answer and READY as shorthand for the table.

## Install

```bash
uv tool install git+https://github.com/infiquetra/talaria@v0.1.0
talaria --version
```

**Do not `uv tool install talaria`.** That name on the Python Package Index belongs to an unrelated content management system whose last upload was 2010-06-19. Talaria is deliberately not published there: two of the limits above are exactly the claims a package index would make on your behalf.

Requires Python 3.12 or 3.13. Supported on macOS arm64; see the limits above for what that leaves out.

## Getting a credential

Talaria reads its gateway credential from `~/.talaria/credentials`, written `0600`. With a Hermes dashboard running:

```bash
talaria refresh-credential
```

The dashboard mints its session token at start-up and holds it in memory, so this is needed again after every dashboard restart. The token is never printed.

## What you can do

```bash
talaria                        # dial the configured gateway, open a session
talaria --resume               # pick up the most recent session
talaria --session <id>         # attach to a specific one
talaria --record               # ... and record every frame while you work

talaria record                 # record with no interface at all
talaria replay <recording>     # drive the whole interface from a recording
talaria gate --corpus <rec>    # re-run the framework validation gate
```

In a session, `/models` opens a picker over the models the connected Hermes offers — selecting a row switches the running session, and `<n> default` writes it as the profile's default instead. `/profiles` lists the profiles the gateway knows about with their models and liveness, and selecting one dials that profile's gateway. Both are plural deliberately: Hermes owns the singular `/model` and `/profile`, and both are marked `local` in the command listing so the one-character difference is visible.

In replay, `F8` pauses and `F9`/`F10` change speed. Controls that would change something on a gateway are visibly inert.

## On credentials

A credential is never written to a frame log, a transcript export, a diagnostic record or a status payload, and Talaria puts none into its own command line or environment. An endpoint carrying a credential in its query string, userinfo or fragment is **refused** rather than quietly stripped — on the command line and in `TALARIA_GATEWAY_URL` alike.

The redaction is not merely tested against itself: a frozen TypeScript reference implementation is run in a subprocess on every suite run and the Python recorder is asserted to match it.
