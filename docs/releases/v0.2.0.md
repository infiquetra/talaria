Talaria is an experimental, Hermes-native terminal UI. This release makes the interface answerable, makes `--resume` mean what it says, and renders the transcript as real markdown.

Two legs, each merged behind its own measured gate. The answerability spine was hardened through six external review rounds — 41 verified findings fixed, every fix pinned by a revert-checked test. The block-markdown build passed a 24-of-24 full-scale replay gate — a 50,000-delta stress corpus, a feature corpus covering every markdown construct, a sustained-cadence pass, and adversarial workloads at full size — with the exact figures, the run-by-run record, and two operator-approved measurement amendments published in [the gate results](https://github.com/infiquetra/talaria/blob/v0.2.0/docs/analysis/2026-08-09-block-markdown-gate-results.md).

## Read this part first

v0.1's limits still stand where they are not superseded:

- **No person has driven the interface on Linux.** The suite runs there in continuous integration; nobody has used it there.
- **No run on either platform has used a real terminal emulator.** Every gate measurement was taken against a bare pseudo-terminal.
- **A credential your shell exported before Talaria started is still visible** in the process environment for the life of the process. Use the credential file.

New limits this release records rather than hides:

- **A still-open streaming table re-renders wholesale per append** and crosses the 50 ms apply ceiling at roughly 340 rows until the 500-row fallback demotes it — recorded verbatim in the gate results (`block_phase_peak_ms`), with the early-demotion fix queued.
- **The one-time fallback demotion of a monster entry costs 100–290 ms** in a single apply, excluded from the enforced quantile and reported verbatim per workload.
- **An ambiguous approval outcome settles and latches** rather than restoring the card: the approval wire carries no request id, so a restored card could be a zombie no keystroke can kill. Over-latching self-heals through gateway expiry.

## What is new to use

- `F1` jumps to the newest unanswered prompt; every prompt kind carries its own hint line and focus tint; `Escape` declines per kind (an approval sends an explicit `deny`); `F4` sweeps the answerable set. Typed text survives a refused decline.
- `--resume` renders the resumed session's history — content-preserving, with unreadable rows surfaced rather than dropped and withheld history named.
- `/sessions` opens a picker over the gateway's sessions; selecting one switches the running interface, replacing the outgoing transcript cleanly.
- Committed assistant and reasoning entries render as markdown block documents — headings, fenced code, lists, tables, block quotes — and both in-flight streams render progressively in live documents at the same 50 ms cadence. Degenerate content falls back to bounded, clipped line rendering behind a one-row banner.
