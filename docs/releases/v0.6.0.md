# Talaria v0.6.0

Talaria v0.6.0 is a configurable daily-driver follow-up to v0.5.0. It answers
ten manual-test findings against the v0.5 implementation: honest gateway
compatibility reporting, Herdr-safe keyboard defaults, single-Enter picker
dispatch, inspector-housed diagnostics, a script-driven multirow bottom bar,
marketplace theme import with explicit Reload, a fifth Homebrew theme with
sparse inheritance, and status-script credential hardening. This document is a
candidate record, not a promotion: read the limits first, then the reasons to
upgrade, then the findings-to-evidence map.

## Read this part first

Carried forward from earlier releases and still true:

- **No person has driven the interface on Linux.** The suite runs there in continuous integration;
  nobody has used it there. macOS remains the supported platform.
- **A credential your shell exported before Talaria started stays visible** in the process
  environment for the life of that process. Use the credential file.
- **A fresh launch with no stored credential shows a password prompt you cannot cancel.**
  `talaria/transport/credentials.py` is untouched by this release.

New to this release, and the limits to weigh hardest:

- **`Ctrl+S` cross-context live validation is outstanding.** The cancel chord is safe by
  construction — if a terminal or nested Herdr session captures it (XON/XOFF flow control),
  nothing silently substitutes; reconfigure through the `[keys]` surface instead. The
  per-context live protocol with non-destructive actions remains operator-run.
- **Marketplace import trusts the source you select, with no additional policy.** Talaria
  accepts a user-selected publisher, extension, or direct `https://` reference as configured.
  Fetched packages are parsed as data and never executed, and any failure preserves the
  current theme — but source selection itself is the operator's call.
- **There is no theme file watcher.** Editing a theme source changes nothing live; the new
  values apply on the next explicit `/theme reload`, which repaints the running screen.
- **Older gateways stay silent, newer shapes still drift.** The `commands.catalog` baseline
  pins the observed `commands` metadata key when present but tolerates its absence, so a
  gateway predating the key reports no break it never had. A genuinely new or wrong-typed
  key still drifts loudly.
- **A v1 status script that prints a JSON object line now trips the document protocol.**
  Only a JSON *object* engages the version-2 bar intake; anything else on that path keeps
  the previous good render with a notice instead of rendering. Scripts that print plain
  text render byte-identically to v0.5.0.

## Reasons to upgrade

### Honest gateway compatibility

The `commands.catalog` drift check models the gateway's supported response including the
observed `commands` metadata map — carried as metadata, never merged into dispatchable
rows — and `/model` failures surface the gateway's own refusal instead of an invented
method. See [Gateway compatibility](https://github.com/infiquetra/talaria/blob/main/talaria/domain/commands.py).

### Herdr-safe keyboard defaults

The inspector toggle defaults to `Ctrl+O` (configurable; `Ctrl+B` stays documented as
replaced because Herdr captures it when nested) and turn-cancel defaults to `Ctrl+S`
(configurable; `Ctrl+C` is unbound and `F4` remains an alias). Quit stays on `Ctrl+Q`,
and the footer always labels cancel-turn beside quit-client. See
[Configuration](https://github.com/infiquetra/talaria/blob/main/docs/configuration.md) and
[Terminal UI](https://github.com/infiquetra/talaria/blob/main/docs/terminal-ui.md).

### Single-Enter picker dispatch

Enter on a selected slash-command entry executes it exactly once through the same funnel
as typed input — required arguments are still demanded, confirmation gates still gate,
and repeats never double-dispatch.

### Inspector-housed diagnostics

Routine seam rows (roster, approval detail, HTTP runner, Kanban dispatcher) moved into
the inspector under the operator-action-required rule; actionable failures, markers, and
focus rows stay in the region, and a failed move leaves the row visible rather than
dropping it.

### Script-driven multirow bottom bar

A status script can emit a version-2 JSON document (`{"version": 2, "rows": [...]}`)
to render script-controlled rows on the true-bottom bar with safe colors, bounds, and
responsive fallback — one runner, no second scheduler. Plain-text scripts render exactly
as before, and script edits take effect on the next refresh without restart. See the
[status-line format](https://github.com/infiquetra/talaria/blob/main/docs/formats/status-line.md).

### Marketplace theme import with explicit Reload

Search, fetch, and import marketplace themes with no manual download step, preview with
`/theme select`, persist explicitly, and re-import edited sources with `/theme reload`
— no file watcher, failures preserve the current theme. See
[Themes](https://github.com/infiquetra/talaria/blob/main/docs/themes.md) and the
[import format](https://github.com/infiquetra/talaria/blob/main/docs/formats/vscode-theme-import.md).

### Homebrew and sparse inheritance

Homebrew joins as the fifth built-in with a restrained green-black palette and documented
provenance — present by default, never startup-selected. Every theme resolves through
shared defaults, host palette, per-category groups, and individual overrides, with the
startup selection unchanged. Independent category text colors, marker/background
controls, and a reclaiming left-offset removal round out configurability.

### Status-script credential hardening

Four provider credential names stay denied even when allowlisted, malformed
`environment.allowlist` values fall back to the empty default instead of iterating or
raising, and URL-path redaction plus descendant-process cleanup hold.

## What changes when upgrading from v0.5.0

Configuration gains `[keys]` (`toggle_inspector`, `interrupt`), the status allowlist falls
back to empty for any non-list shape instead of iterating or raising, and the startup
theme selection is unchanged. A clean seam board renders an empty region with the rows
in the inspector; a stale row returns to the region. Scripts and theme sources behave
as their format documents describe; nothing here promotes, publishes, or deploys.
