## Read this part first

- **The workspace is optional.** The default inline view keeps finished output
  in native terminal scrollback. The workspace uses the whole screen; while it
  is open, native scrollback and terminal search do not cover the conversation.
  Finished output waits in memory until you return to inline view, so a process
  crash can lose it.
- **Client voice is opt-in.** Capture and playback helpers run on your machine
  and must be installed and configured separately. Sending audio to a remote
  gateway requires explicit `remote_audio = true`; attaching remotely alone
  does not grant that permission.
- **Check your gateway.** The pinned Hermes contract is <pinned_tag>; Talaria
  accepts a gateway from Hermes <floor> onward.
  Run `talaria doctor` to check the gateway you use.

target/release/talaria --version
