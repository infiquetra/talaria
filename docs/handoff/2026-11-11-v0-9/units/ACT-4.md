## The card stack

Down stops on the last offered choice (`stack.rs:320-323`). Keys are ignored while `answering` is true (`stack.rs:263`). `answering` is `sent`, or a prompt state other than `Open` (`stack.rs:66-69`). A clarify card numbers an extra `Other` row (`stack.rs:638-646`) and the hint counts it (`stack.rs:665-668`). Tab from the choices sets `field` (`stack.rs:325-328`). Esc or Tab in the note field sets `field` to false and keeps `text` (`stack.rs:294-299`). Esc denies when deny was offered (`stack.rs:337-339`). Otherwise Esc removes the card and notes `closed without an answer: Hermes did not offer deny` (`stack.rs:340-348`). `handle_paste` is at `stack.rs:364` and calls `Card::insert` (`stack.rs:71-84`), which keeps the first line and appends it only when `field` is set. `Card::answer` (`stack.rs:106-116`) copies non-empty `text` into the approval note. Choices are drawn by `add_choice` (`stack.rs:705-716`), which always prints a number. The note line uses the prefix `note: ` (`stack.rs:604-605`). The offered-choice hint uses `choices.len()` (`stack.rs:607-609`).

## The steer path

`QueueIntent::SteerText` is handled by `steer_text` (`crates/talaria-core/src/queue/intents.rs:360`). `refuse_busy` (`intents.rs:62-67`) runs before the empty check (`intents.rs:361-367`). It notes `notices::BUSY`, which is `Still moving prompts…` (`crates/talaria-core/src/queue/notices.rs:7`). `take_back` (`crates/talaria-core/src/queue/flow.rs:687-694`) pushes the text to `queue.returned` and notes `notices::DRAFT_KEPT`. Empty text returns no effects (`intents.rs:365-367`). No running turn returns `Effect::SendPrompt` (`crates/talaria-core/src/session/reducer.rs:265-270`), which the app sends as `prompt.submit` (`crates/talaria-app/src/sessions.rs:336-337`). That path does not call `session.steer`. The branch starts at `intents.rs:369`.

`Effect::Steer` is sent at `crates/talaria-app/src/queue.rs:91-105` as `session.steer` (`queue.rs:102`). Success becomes `Event::SteerResult`. Failure goes through `failure_event` (`queue.rs:164-204`), which can be `Event::QueueCallRefused` or `Event::QueueCallUnknown`. `on_refused` for `QueueAction::SteerText` (`flow.rs:757-771`) resubmits for `stale_generation`, `execution_not_ready`, and `unsupported_control`, and otherwise returns the text. `steer_answer` (`flow.rs:889-919`) resubmits when status is `Rejected` and `delivered` is false, and returns the text on a plain `Rejected`. `CanonicalCorrectionAck` (`crates/hermes-contract/src/generated/schemas.rs:1770-1776`) has no reason field.

`QueueState::busy` is `pub(crate)` and is `plan.is_some() || in_flight.is_some()` (`crates/talaria-core/src/queue/mod.rs:423-424`). `plan` is public at `queue/mod.rs:142` and `in_flight` at `queue/mod.rs:144`. `InFlight` has public fields (`queue/mod.rs:113`). `SessionState.queue` is public (`crates/talaria-core/src/session/state.rs:137`). `take_returned` is public (`queue/mod.rs:395`). `update` keeps only the first returned string and pushes `AppEffect::OfferDraft` (`crates/talaria-app/src/app.rs:4534-4539`).
