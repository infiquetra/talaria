## 3. Exact request and response shapes

```text
GET  <base>/api/status
  200 {..., "auth_required": true, "auth_providers": ["basic"], "auth_flows": ["cookie","native_pkce"]}

GET  <base>/auth/native/authorize?code_challenge=<c>&code_challenge_method=S256&redirect_uri=<enc>&state=<s>[&provider=<p>]
  ... the browser finally receives 302 http://127.0.0.1:<port>/callback?code=<gw_code>&state=<s>

POST <base>/auth/native/token        {"code": "<gw_code>", "code_verifier": "<v>"}
  200 bearer payload | 400 {"detail":"Invalid or expired authorization code."} | 422 (body rejected) | 5xx

POST <base>/auth/native/refresh      {"refresh_token": "<rt>", "provider": "<p>"}
  200 bearer payload | 400 | 401 {"error":"session_expired",...} | 503

GET  <base>/api/auth/me              Authorization: Bearer <at>
  200 {"user_id","email","display_name","org_id","provider","expires_at"} | 401

POST <base>/api/auth/ws-ticket       Authorization: Bearer <at>
  200 {"ticket":"<t>","ttl_seconds":30} | 401 | 503

GET  wss://<host><prefix>/api/ws?ticket=<t>
  Sec-WebSocket-Protocol: hermes-gateway-v1      (no ticket subprotocol, no Origin, no Authorization)
  101 with no Sec-WebSocket-Protocol             | HTTP 403 (pre-accept refusal) | 404 | 502-504 (tunnel)
  then gateway.ready -> client.capabilities {server_requests: true} -> runtime.describe
  then session.list {"profile": "<name>", "limit": 1}
```

Bearer payload: `{"access_token","refresh_token","token_type":"Bearer","expires_at":<unix s>,"provider","user_id"}`.

## 5. State machines

Sign-in:

```text
Idle ─probe ok─► Listening(port, verifier, state) ─callback or paste─► Callback
  │                  │ other path ─► 404, stay Listening
  │                  │ Ctrl+C ──► Cancelled (listener closed, nothing saved)
  │                  │ 600 s ───► TimedOut  (listener closed, nothing saved)
probe fails ─► Refused(reason)
Callback ─error param────► Denied(text)          (no token call; listener closed)
Callback ─state mismatch─► StateMismatch         (no token call; listener closed)
Callback ─ok─► Exchanging ─200─► Saved ─► Done
                         ├─400─► CodeRejected     ┐
                         ├─422─► RequestRejected  ├ never retried
                         └─5xx/timeout/drop─► OutcomeUnknown ┘
```

Attach (`RemoteDial::dial`, once per attempt): re-read the token file → refresh if within 60 s of expiry (200 save; 401 clear and `GiveUp`; 503 keep and `Retry`) → mint a ticket (401 → one refresh and one retry; a second 401 is `GiveUp`) → dial → handshake in unknown-identity mode → on the first attempt only, `session.list {profile, limit: 1}` (`profile_mismatch` → `GiveUp`) → `Dialed`.

## 6. Mock gated gateway

`crates/hermes-client/tests/support/mock_gated.rs`, also run by `examples/mock_gated_gateway.rs` (which includes it by `#[path]`, since `tests/` is not importable). It is an HTTP and WebSocket server on `127.0.0.1:0`, plain or TLS. Every Hermes-derived behaviour cites a row of section 2. Two behaviours are **test-only shortcuts**, named in its rustdoc and in the journal entry:

1. `/mock/approve?broker=…` and `--auto-approve` stand in for the provider round trip. Real Hermes keeps the broker in a cookie on its own origin and reaches the loopback redirect only after the provider.
2. A ticket subprotocol is always refused with HTTP 403. This models a non-loopback peer (section 2.7); real Hermes would fall through for a loopback peer.

Shared rules: the method check is case-insensitive like Hermes; codes expire after 120 s and are popped before the PKCE check; a 422 is returned for a body missing either field; tickets expire after 30 s, are single use, and are valid only as `?ticket=`; the upgrade accepts with **no** subprotocol echo; issued values start with `SENTINEL-`; access tokens default to 12 h. The request log prints the method, the path and the query keys with values replaced by `[redacted]` (`/api/ws?ticket=[redacted]`), plus counters such as `token calls: <n>`. `gateway.ready`, `client.capabilities` and `runtime.describe` replies are copied from [`P1-04`](https://github.com/infiquetra/talaria/issues/201)'s recorded frames in `fixtures/frames/`. If those frames lack a field this mock needs, stop and report it rather than writing one by hand.

## 8. Secrets and capture

- Never output, log, record or capture as evidence: access token, refresh token, verifier, code, ticket. `state` appears only in the one authorize-URL display (REQ-4). The paste line is read with echo off and never printed.
- Recording: frames go through [`P1-04`](https://github.com/infiquetra/talaria/issues/201). The dial URL (with `?ticket=`) is passed as the recorder header's `endpoint`, where [`P1-04`](https://github.com/infiquetra/talaria/issues/201)'s URL rule (its REQ-7) redacts the `ticket` value. The remote host is given as a [`P1-04`](https://github.com/infiquetra/talaria/issues/201) substitution (its REQ-11) mapping to `gateway.example.com`.
- HTTP traffic is never recorded in normal use. The probe example writes HTTP exchanges through `remote/capture.rs`, which: replaces the values of the JSON keys `access_token`, `refresh_token`, `code`, `code_verifier`, `state`, `ticket`, `code_challenge`, `user_id`, `email`, `display_name`; replaces the values of the same names in URL queries; drops `Authorization` and `Cookie` headers; and maps the remote host to `gateway.example.com`. Test 35 feeds it a full mocked flow and searches the output for `SENTINEL-`.
- A secret found anywhere is deleted, not committed, and reported.

## 11. Design reasoning

- **`?ticket=` over `?token=`:** both are accepted (2.6). A ticket lasts 30 s and works once; an access token lasts hours (12 h by default for `basic-auth`) and would sit in tunnel and proxy logs.
- **`?ticket=` over the ticket subprotocol:** the subprotocol form depends on the peer address the gateway sees (2.7). The query form does not. The cost is that no subprotocol is echoed (2.6), which the remote dial accepts.
- **Widening the transport alias** instead of a parallel connection type keeps [`P1-02`](https://github.com/infiquetra/talaria/issues/199), [`P1-03`](https://github.com/infiquetra/talaria/issues/200) and [`P1-12`](https://github.com/infiquetra/talaria/issues/209) unchanged. `MaybeTlsStream::Plain` costs one enum match per read.
- **Unknown identity:** a dashboard ticket carries no gateway identity (2.5), so there is nothing to compare at first attach. TLS and the bearer token authenticate the server and the user. Later attaches report an `instance_id` change as a restart, as the local path does after rediscovery.
- **A profile injector** instead of editing every parameter builder: one place, checked against the contract, covering [`P1-03`](https://github.com/infiquetra/talaria/issues/200)'s replay calls too.
- **Exit code 1:** [`P1-12`](https://github.com/infiquetra/talaria/issues/209) REQ-2 owns the binary's exit codes.
- **No cross-process lock:** Hermes coalesces equal refresh tokens for 30 s (2.5), and REQ-9 re-reads the file before refreshing. The remaining gap: a process holding a stale refresh token for more than 30 s after another process rotated it, with a rotating provider. It is recorded in the journal.
- **Owner-only files, not the keychain:** the Desktop default; a keychain is an operator question.
